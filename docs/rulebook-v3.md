## 1. 게임 개요

- **장르:** K-다크 판타지 심리 서바이벌 TRPG
- **인원:** 인간 플레이어 1~3명, 빈 좌석은 봇이 채움
- **기기 구성**
  - 호스트 PC: **Display 전용**. 방 생성, 전체 상황 중계. **게임 조작은 없다** — 투표·굴림·개입·능력·부적을 Display에서 조작하지 않는다
    - **예외: 방 운영.** 게임 시작, 봇 지정, 일시정지·재개는 룰이 아니라 진행 관리라 호스트 Display가 보낸다 (§21)
  - 플레이어(호스트 본인 포함): 로비에서 QR로 연결한 **폰(Controller)으로만 조작**
- **GM:** System GM. 변이, 환각, 판정, 잠식도 계산을 서버가 자동 처리
- **팀 목표:** 시간 안에 마을 경계(장승)를 넘어 탈출
- **배신자 목표:** 형제들의 탈출 저지

## 2. 시간 구조

### 2.1 게임 시계

| Phase | 구성 | 이벤트 수 | 참고 소요 |
|---|---|---|---|
| Phase 1: 안개 속의 진입 | T1 → T2 → 이장 | 3 | 약 15분 |
| Phase 2: 당산나무 숲의 미로 | 진입 환청 → 분기 → 랜덤 8개 (7번째 보스) | 9 | 약 45분 |
| Phase 3: 장승 앞의 결전 | 엔딩 분기 | 1 | 최대 10분 |
| **합계** | | **13** | **약 65분 + 여유 약 35분 (추정)** |

- 게임 시계는 **100분** [설정값]
- Phase 전환은 **해당 Phase의 이벤트를 모두 마쳤을 때** 일어남
- 시계는 투표, 판정, 개입 창 중에도 계속 흐름
- 시간 페널티는 남은 시간에서 즉시 차감
- **Phase 1~2 중 시계가 0이 되면 즉시 강제 잠식 엔딩.** 진행 중인 판정과 개입 창은 중단. 모든 화면이 노이즈로 덮이고 조작이 잠김
- Phase 3의 시계 규칙은 §14
- 엔딩 연출 20분은 시계 밖에서 진행

### 2.2 이벤트 1회 흐름

1. 상황 제시 (30초) [설정값]
2. 투표 (3분) [설정값]
3. 판정 및 연출 (약 1분)
4. 개입 창 (실패 시에만, 최대 12초)
5. 결과 적용
6. Phase 2 랜덤 이벤트라면 환경 잠식 적용 (§4.2)

## 3. 형제와 직업

| 형제 | 담당 속성 | 담당 판정 보정 | 고유 능력 (게임당 1회) |
|---|---|---|---|
| 첫째 | 근력/보호 | +1 | 강제 성공 |
| 둘째 | 민첩/눈치 | +1 | 재굴림 |
| 셋째 | 지식/도술 | +1 | 절대 시야 |

### 3.1 판정자

- 채택된 선택지의 **속성 담당 형제**가 굴림
- 담당 형제가 봇이면 봇이, 배신자여도 그 형제가 굴림
- 직업 보정 +1은 **담당 속성 개인 판정과 비공개 판정에만** 적용. 협동 판정과 대립 판정에는 없음

### 3.2 첫째 — 강제 성공

- **발동 시점:** 다른 형제의 판정이 실패했을 때, 개입 창 3단계
- **효과:** 본인 잠식도 +15% [설정값], 판정 결과를 성공으로 변경
- **보상 규칙:** 실패 결과를 무효화하고 **보상은 제거**하되, **성공 결과에 포함된 부작용은 그대로 적용**

| 판정 | 원래 성공 결과 | 강제 성공 시 |
|---|---|---|
| 이장 B | 부적 + 판정자 +5% | 부적 없음, +5% 적용 |
| 이장 C | 다음 판정 +1 + 전원 +10% | 버프 없음, 전원 +10% 적용 |
| 분기 B (사당) | 옥비녀 + 전원 +10% | 옥비녀 없음, 전원 +10% 적용 |
| 보스 A | 부적 2개 + 통과 | 부적 없음, 통과 |

- **어머니의 옥비녀는 강제 성공으로 얻을 수 없음**
- **사용 가능:** 다른 형제의 개인 판정, 협동 판정
- **사용 불가:** 본인 판정, 비공개 판정, 14A(아이템 사용), Phase 3 전체
- **첫째가 배신자일 때:** 정상 발동. 게이지는 100%에서 변하지 않지만 Display 연출은 동일
  - Display: "첫째가 자신의 영혼을 깎아 형제를 구원합니다"

### 3.3 둘째 — 재굴림

- **발동 시점:** 개입 창 1단계
- **개인 판정:** 누구의 판정이든 주사위를 다시 굴려 결과를 대체
- **협동 판정:** 본인이 굴린 주사위 1개만 다시 굴림
- **Phase 3:** 팀 측 주사위에만 사용 (B-1은 옥비녀 보유자의 주사위, A-2는 본인 주사위)
- **둘째가 배신자일 때:** 정상 발동

### 3.4 셋째 — 절대 시야

- **발동 시점:** 이벤트 투표 시간 중
- **효과:** 해당 이벤트 **모든 선택지의 실제 변이**(흉/평/길)를 열람
- 항상 진실을 보여줌. 60% 티어의 가짜 라벨이 적용되지 않음
- **셋째가 배신자일 때:** 버튼 유지. 사용 시 연출과 횟수 소모는 동일하고, 새로 얻는 정보는 없음 (이미 전부 보이므로)

### 3.5 고유 능력 공통 규칙

- 사용 사실은 Display에 **형제 이름과 함께 공개**
- 배신자여도 버튼을 숨기거나 비활성화하지 않음
- T1, T2 중 사용은 **횟수를 소모하지 않음** (첫째의 +15% 대가는 적용). 봇 좌석에도 동일하게 적용한다

## 4. 잠식도

### 4.1 기본 규칙

- 개인값, 0~100%, 5% 단위
- **본인 폰에만 표시.** Display에는 어떤 형태로도 표시하지 않음
- 결과 대상 표기
  - "판정자": 그 판정을 굴린 형제 1명
  - "전원": 봇과 배신자를 포함한 형제 전원
- 100% 초과분은 버리고, 0% 미만으로 내려가지 않음

### 4.2 환경 잠식

- **Phase 2 랜덤 이벤트 8개가 각각 끝날 때마다 전원 +5%** [설정값]
- 판정 결과, 강제 성공 여부와 무관하게 적용
- Phase 1, 분기, Phase 3에는 적용하지 않음

### 4.3 잠식 티어

| 구간 | 효과 |
|---|---|
| 0~29% | 정상 |
| 30~59% | Phase 2 랜덤 이벤트 시작 시 50% 확률로 **티어 환청** 1회 (진실 30% / 거짓 70%) [설정값] |
| 60~99% | 티어 환청 확률 100%. 이벤트마다 30% 확률로 본인 폰에 **가짜 흉/평/길 라벨** 표시. **가짜 붉은 메시지** 발동 [설정값] |
| 100% | **이면의 형제(배신자)** 전환 (§10). 봇은 방해 효과 발동 (§11) |

- **100% 구간은 티어 환청·가짜 라벨·가짜 붉은 메시지의 대상에서 제외한다.** 배신자는 이미 모든 선택지의 실제 변이를 열람하므로(§10.2) 가짜 정보가 의미가 없다. 티어 효과는 30~99% 구간에만 적용된다

### 4.4 회복

- 회복 수단: 이벤트 회복 결과, 낡은 부적(-10%)
- **배신자는 회복 대상에서 제외.** 게이지는 100%로 유지되고, 제외 사실은 어디에도 표시하지 않음
- **100%는 비가역.** 어머니의 옥비녀 정화로만 해제 (엔딩 서사)

## 5. 판정

### 5.1 계산

```
최종값 = D6 + 직업 보정 + 버프/디버프 + 부적
최종값 ≥ 성공 기준 → 성공
```

### 5.2 판정 유형

| 유형 | 굴리는 사람 | 보정 | 결과 공개 | 개입 창 |
|---|---|---|---|---|
| 개인 판정 | 판정자 1명 | 담당 +1 | 공개 | O |
| 협동 판정 | 전원 (봇·배신자 포함) | 없음, 최고값 사용 | 공개 | O |
| 비공개 판정 | 판정자 1명 | 담당 +1 | **비공개** | X |
| 아이템 사용 판정 | 없음 (14A) | - | - | X |
| 대립 판정 | Phase 3 | 없음 | 공개 | 팀 측만 |

### 5.3 협동 판정

- 성공 기준: T2와 Phase 2 일반 **5 이상**, 보스 **6** [설정값]
- 최고값 방식이라 배신자의 주사위는 결과를 방해하지 못함
- **보상 수령자:** 개입 후 **최종 최고값 주사위의 주인** (부적 +1이나 재굴림으로 갱신된 주사위 포함). 동점이면 랜덤

### 5.4 비공개 판정

- **대가:** 성공/실패와 무관하게 판정자 잠식도 **+10% 고정** [설정값]
- 판정 결과는 **판정자를 포함한 누구에게도 공개하지 않음**
- 결과는 귓속말의 진실/거짓 여부에만 영향 (성공 = 진실, 실패 = 거짓)
- Display 표시: "판정 완료"
- 선택지 표기 (수치 비공개 원칙의 유일한 예외):
  `판정: 비공개 [지식/도술] (대가: 잠식도 10% 상승)`

### 5.5 버프와 디버프

- **1회성 팀 플래그.** 팀의 다음 1회 판정에 적용된 뒤 소멸
  - 개인 판정: 결과값에 적용
  - 협동 판정: 최고값에 적용
  - 비공개 판정: 결과값에 적용
  - 대립 판정: 팀 측 값에 적용
  - 14A 아이템 사용 판정: 적용하지 않고 다음 판정으로 이월
- **디버프 합계 하한 -2.** 버프와 디버프는 합산
- Display에는 **출처 없이 익명 표시:** "누군가의 불길한 기운 -1"

| 발생원 | 효과 |
|---|---|
| 이장 A 실패 | -1 |
| 이장 C 성공 | +1 |
| Phase 2 진입 환청 (부적 미보유자 1명당) | -1 |
| 봇 100% 방해 | -1 (방해 효과로 선택된 경우) |

## 6. 흉/평/길 변이

### 6.1 결정

- 이벤트가 출현할 때 서버가 **선택지마다** 몰래 결정
- 발생 비율: 흉 30% / 평 50% / 길 20% [설정값·초안]

### 6.2 효과

변이는 수치를 곱하지 않고 **가산**합니다.

| 선택지 종류 | 흉 | 평 | 길 |
|---|---|---|---|
| 판정 선택지 (개인·협동) | 성공 기준 +1 (상한 6), 실패 잠식 페널티 +10%p | 변화 없음 | 보상이 있으면 보상 +1단계, 없으면 실패 잠식 페널티 -10%p (최소 0%) |
| 판정 없는 선택지 | 시간 페널티 +5분 | 변화 없음 | 시간 페널티 -5분 (최소 0분) |
| 비공개 판정 | 성공 기준 +1 (상한 6) | 변화 없음 | 성공 기준 -1 (하한 2) |

- 성공 기준이 이미 6이면 흉은 페널티 가산만 적용
- 실패 페널티 가산은 **잠식도 페널티에만** 적용. 대상이 전원이면 각자에게 가산. 실패 시 시간 페널티(11A)는 불변
- **흉과 길의 시간 가감은 이미 있는 시간 페널티만 가감한다.** 시간 페널티가 없는 선택지에는 페널티를 새로 만들지 않는다
- 비공개 판정의 대가 +10%는 변이와 무관하게 고정
- **보상 +1단계:** 부적은 +1개, 잠식도 회복은 +5%p
- 증가 가능한 보상이 여러 개면 **그 보상을 전부 한 단계씩** 올린다
- 옥비녀 보상은 증가할 수 없으므로, 분기 B의 길은 실패 페널티 -10%p로 적용
- 버프 보상(팀 다음 판정 +1)도 증가시키지 않는다. 보상이 버프뿐인 선택지(이장 C)의 길은 실패 페널티 -10%p로 적용

### 6.3 적용 범위

| 적용 | 미적용 |
|---|---|
| 이장 이벤트, 분기, Phase 2 랜덤 이벤트, 보스 | T1, T2, 14A 선택지, Phase 3 |

### 6.4 열람과 표기

- **일반 투표 화면:** 상황 문장, 선택지 문장, 판정 유형과 속성 태그만 표시
  - 성공 기준, 보상, 페널티, 시간 수치는 비공개 (예외: 비공개 판정의 대가)
- **변이 열람:** 배신자(항상), 셋째(능력 사용 시)
- **가짜 라벨:** 60~99% 플레이어의 폰에 확률적으로 표시
- 열람 화면에는 **라벨과 최종 적용값을 함께** 표기. Display에는 표시하지 않음

```
예) 07A 성황당 정화 (기준 5, 실패 +25%)에 흉이 걸린 경우
[흉] 성공 6 이상 · 실패 시 +35%
```

## 7. 개입 창

### 7.1 열리는 조건

- **공개 판정이 실패했을 때만** 열림 (개인 판정, 협동 판정, Phase 3 팀 측 패배)
- 비공개 판정, 14A, 성공한 판정에서는 열리지 않음
- 예외: T1과 T2의 성공 시에는 연습 개입 창 (§12)

### 7.2 순서

| 단계 | 수단 | 시간 [설정값] |
|---|---|---|
| 1 | 둘째 재굴림 | 4초 |
| 2 | 낡은 부적 +1 | 4초 |
| 3 | 첫째 강제 성공 | 4초 |

- 각 단계가 끝나면 재판정. **성공으로 바뀌면 창 즉시 종료**
- **그 단계의 수단이 소모되면 남은 시간을 기다리지 않고 다음 단계로 넘어간다.** 부적은 판정당 1개라 다른 보유자도 쓸 수 없고, 사용 사실은 어차피 공개되므로 정보가 새지 않는다
- 싼 자원부터 쓰는 순서이며, Display에 단계별로 중계

### 7.3 단계 스킵

- **둘째·첫째 단계:** 해당 능력을 이미 사용했거나 이번 판정에 사용할 수 없으면 조기 스킵 (사용 사실이 공개 정보라 새는 정보 없음)
- **부적 단계:** 성공으로 바뀐 경우 외에는 **스킵 금지.** 보유자가 아무도 없어도 4초 대기

### 7.4 부적 사용

- **판정당 1개만** 적용
- 여러 명이 동시에 누르면 **서버에 먼저 도달한 1명만 적용**, 나머지 버튼은 즉시 비활성화
- 적용되지 않은 사람의 부적은 소모되지 않음
- 소유자는 **누구의 판정에든** 사용 가능
- 사용자는 Display에 이름과 함께 공개

### 7.5 기타

- 입력 마감 판정에 서버 유예 0.3초 [설정값]
- 개입 창 중에도 게임 시계는 흐름

## 8. 투표

- **다수결.** 투표권은 인간 플레이어 전원(배신자 포함). 봇은 투표하지 않음
- **블라인드 투표:** 투표 중 득표 현황 비공개 → 마감 후 **득표 수만 일괄 공개**, 투표자는 끝까지 비공개
- 투표 시간 3분 [설정값]. 전원이 투표를 마치면 조기 마감
- 미투표자는 기권 처리
- 동률이면 **동률 선택지 중에서** 무작위, 전원 기권이면 **전체 선택지 중에서** 무작위 (Phase 1~2)
- Phase 3 투표는 §14.4
- 1인 플레이는 본인의 선택이 곧 결정
- 투표 시간 중 가능한 행동: 토론, 셋째 절대 시야, 부적 회복 사용

## 9. 아이템

### 9.1 낡은 부적 (소모성)

- **개인 소유.** 획득한 형제의 인벤토리에 들어감 (협동 보상은 §5.3)
- **보유 여부는 비공개, 사용 사실은 공개**
- 인당 보유 상한 **2개** [설정값]. 초과 획득 시 다른 형제에게 양도하거나 버림
- **용도 택1**

| 용도 | 시점 | 효과 |
|---|---|---|
| 판정 보정 | 개입 창 2단계 | 최종값 +1 (판정당 1개) |
| 잠식도 회복 | 투표 시간 중 | 본인 잠식도 -10% [설정값] |

- 배신자도 두 용도 모두 사용 가능. 회복 용도는 게이지가 변하지 않지만 소모와 공개 연출은 동일

### 9.2 튜토리얼 부적

- T1 진입 시 **인간 플레이어 1명에게 랜덤 지급** (봇 제외)
- T1 동안만 유효. **T1 종료 시 소멸**하여 본게임 경제에 영향 없음
- **용도는 판정 보정(개입 창 2단계)으로만 제한한다.** §9.1의 잠식도 회복 용도로는 사용할 수 없다
  - T1 시점에는 잠식도가 0%라 회복 효과가 없고 부적만 소모되기 때문이다
  - 회복에 쓸 부적을 셀 때 튜토리얼 부적은 세지 않는다. 튜토리얼 부적만 가진 좌석의 회복 요청은 거절한다

### 9.3 어머니의 옥비녀 (핵심 키아이템, 비소모성)

- **획득:** 분기 B(핏빛 사당) 판정 성공 시 판정자
- 강제 성공으로는 획득 불가
- 보유 여부는 비공개. Phase 3에서만 사용
- Phase 3 진입 시 보유자가 타겟이면 다른 형제에게 이동 (§14.1)

## 10. 이면의 형제 (배신자)

### 10.1 전환

- **조건:** 인간 플레이어의 잠식도가 100%에 도달하는 즉시
- **1인 플레이 예외:** 배신할 상대가 없으므로 배신자 모드 없음. 대신 §11의 봇 100% 방해 효과를 본인에게 적용
- **전환 연출:** 본인 폰에만 붉은 메시지를 **3초** 표시 후 소멸 [설정값]
  > 당신은 요괴에 잠식되었습니다. 형제들을 파멸로 이끄십시오.
- 이후 UI는 일반 플레이어와 완전히 동일
- 60~99% 플레이어에게도 같은 형태의 **가짜 붉은 메시지**가 발동하므로, "붉은 화면 = 배신자"가 성립하지 않음

### 10.2 권한과 정보

- **조작권 유지.** 봇 대행은 연결이 끊겼을 때만 적용
- **정보 우위:** 모든 이벤트의 모든 선택지 **실제 변이를 항상 열람**
- 투표, 판정, 고유 능력, 부적 사용 모두 일반 플레이어와 동일하게 가능
- Phase 2 협동 판정에도 참여 (참여하지 않으면 정체가 드러나므로)
- 주요 방해 수단: 투표 유도, 개입 포기, 부적 은닉, 거짓 정보 발언

### 10.3 승리 조건

- **형제들이 탈출하지 못하면 승리** (엔딩표 §15)
- 배신자가 여러 명이면 승패를 공유
- 살아있는 인간 플레이어가 **전원 배신자가 되는 즉시 강제 잠식 엔딩**

### 10.4 회복

- 모든 회복 효과에서 제외. 100%는 비가역

## 11. 봇

- **투표하지 않음.** 판정 굴림만 담당
- 잠식도가 인간과 동일하게 증감
- **부적 자동 사용:** 실패가 확정됐고, +1로 성공으로 바꿀 수 있을 때만 판정 보정 용도로 사용
  - **판단 시점은 부적 단계 진입 즉시가 아니라 단계 마감 1초 전** [설정값]. 그때까지 아무도 부적을 사용하지 않은 경우에만 사용한다
  - 진입 즉시 사용하면 봇이 선착순(§7.4)을 항상 선점해 인간 보유자에게 기회가 가지 않기 때문이다
- **고유 능력**

| 좌석 | 규칙 |
|---|---|
| 둘째 봇 | 판정 실패 시 개입 창 1단계에서 자동 재굴림 (1회). 협동 판정에서는 본인 주사위가 현재 최고값일 때만 사용 |
| 첫째 봇 | 보스 이벤트 실패 시에만 사용 |
| 셋째 봇 | 투표권이 없으므로 사용하지 않음 |

- **100% 방해:** 게임당 1회, **발동 가능한 수단 중** 하나가 랜덤 발동
  - 팀의 다음 판정 -1 (디버프 합계 하한 -2 적용)
  - 부적 보유자 1명의 부적 1개 소멸
  - **부적 보유자가 아무도 없으면** 부적 소멸은 후보에서 빠지고 팀 디버프만 후보가 된다. 보류함 부적은 쓸 수 없으므로 보유로 세지 않는다
  - **"게임당 1회"는 효과가 실제로 일어나는 1회를 뜻한다.** 빈손으로 소모되지 않는다
- 봇은 배신자가 아니며, 엔딩 승패에 참여하지 않음
- 연결이 끊긴 인간 플레이어를 대행 (배신자 포함)

## 12. Phase 1: 안개 속의 진입

**배경 에셋:** 초가 마을

### T1. 안개 낀 진입로 (튜토리얼)

**상황:** 마을 어귀로 들어서는 좁은 길을 쓰러진 고목이 막고 있다.
**진입 연출:** "길바닥에서 낡은 부적 1개를 주웠다" → 튜토리얼 부적 지급 (§9.2)

| 선택지 | 판정 | 기준 | 성공 | 실패 |
|---|---|---|---|---|
| A. 힘으로 고목을 밀어낸다 | 개인 [근력/보호] | 4 | 통과 | 통과 |
| B. 틈 사이로 기어 지나간다 | 개인 [민첩/눈치] | 4 | 통과 | 통과 |

**특수 규칙**
- 변이 없음, 실패 페널티 없음
- 판정 실패 시: **실전 개입 창** (효과 실제 발동, 능력 횟수 미소모, 첫째 +15% 대가 적용)
- 판정 성공 시: **연습 개입 창.** 부적·재굴림·강제 성공 버튼을 눌러볼 수 있고, 효과는 설명 팝업으로만 보여줌
- 판정자가 첫째여서 강제 성공을 쓸 수 없는 경우, 첫째 단계에서 "형제의 판정에서 이렇게 쓴다"는 설명 표시
- 연습 개입 창은 **단일 단계 12초** [설정값]. 실전 개입 창과 달리 3단계로 나누지 않는다
- 판정자가 첫째여도 첫째 단계를 조기 스킵하지 않는다. 튜토리얼에서는 이 규칙이 §7.3의 조기 스킵보다 우선한다
- 튜토리얼 부적: 실전 개입 창에서는 실제로 사용·소모된다. 연습 개입 창에서는 소모되지 않는다. 사용 여부와 무관하게 T1 종료 시 소멸
- 튜토리얼 팝업으로 투표, 판정, 개입 창을 안내

### T2. 빈 주막 (튜토리얼)

**두 개의 이벤트(T2-1, T2-2)를 고정 순서로 진행한다.**

**① 협동 판정 (선택지 없음)**
**상황:** 기울어진 주막 대들보가 무너져 내린다. 모두 함께 받쳐야 한다.

| 판정 | 기준 | 성공 | 실패 |
|---|---|---|---|
| 협동 | 최고값 5 이상 | 통과 | 통과 |

- 실패 페널티 없음. 실패 시 실전 개입 창, 성공 시 연습 개입 창 (T1과 동일)
- 선택지가 1개인 이벤트이므로 **투표 단계를 생략하고 바로 판정**한다

**② 투표**
**상황:** 주막 뒤편에 점괘를 담은 항아리가 놓여 있다. 들여다보면 앞길의 길흉이 비친다고 한다.

| 선택지 | 판정 | 기준 | 결과 |
|---|---|---|---|
| A. 항아리를 들여다본다 | 비공개 [지식/도술] (대가: 잠식도 10% 상승) | 4 | 판정자에게 귓속말: **이장 이벤트 선택지 1개의 변이** (성공 = 진실, 실패 = 거짓) |
| B. 그냥 떠난다 | 없음 | - | 페널티 없음 |

- 변이 없음
- 귓속말 발송 시점: 진실/거짓 여부는 T2-2 판정 직후 확정해 저장하고, 내용은 **이장 이벤트가 출현해 변이가 결정된 직후** 생성해 발송한다 (§6.1의 변이 결정 시점을 유지하기 위함)
- 거짓일 때는 실제 변이를 제외한 나머지 두 값 중 무작위 1개를 알려준다

### 이장 이벤트 (Phase 1 본 이벤트)

**탈 에셋:** 기본 광대탈
**상황:** 짙은 안개 속, 입이 찢어진 광대탈을 쓴 이장이 소리 없이 다가온다. "밤이 늦었소... 우리 집에서 몸 좀 녹이고 가시지요." 그의 발뒤꿈치가 땅에 닿아 있지 않다.

| 선택지 | 판정 | 기준 | 성공 | 실패 |
|---|---|---|---|---|
| A. 정중히 거절하고 뒷걸음질 친다 | 개인 [민첩/눈치] | 4 | 변화 없음 | 판정자 +15%, 팀 다음 판정 -1 |
| B. 따라가며 약점을 찾는다 | 개인 [지식/도술] | 4 | 판정자 +5%, 부적 1개(판정자) | 판정자 +20% |
| C. 무기를 꺼내 위협한다 | 개인 [근력/보호] | 4 | 팀 다음 판정 +1, 전원 +10% | 판정자 +25% |

- 변이 적용

## 13. Phase 2: 당산나무 숲의 미로

**배경 에셋:** 당산나무 숲 (기본)

### 13.1 진입 환청

**상황:** 끝없는 고목 숲. 나뭇가지의 오방색 헝겊이 미세하게 흔들리고, 누군가의 귓가에 속삭임이 들린다. "너희들 중 누군가는 이미 껍데기만 남았어. 뒤를 돌아보지 마라."

| 대상 | 결과 |
|---|---|
| 부적 보유자 (봇 포함) | 부적이 뜨겁게 달아오르며 경고 귓속말만 수신. 부적 소모 없음 |
| 부적 미보유자 (봇 포함) | 개인 잠식도 +10% [설정값], 1명당 팀 다음 판정 -1 (익명, 하한 -2) |

### 13.2 분기 (Phase 2 첫 이벤트, 고정)

| 선택지 | 판정 | 기준 | 성공 | 실패 |
|---|---|---|---|---|
| A. 기괴한 울음소리가 나는 오솔길로 돌아간다 | 없음 | - | 시간 -15분 | - |
| B. 요기가 가장 짙은 핏빛 사당을 가로지른다 | 개인 [민첩/눈치] | 5 | **어머니의 옥비녀**(판정자), 전원 +10% | 판정자 +20%, 거짓 귓속말 1회 |

- 변이 적용 (B의 길은 실패 페널티 -10%p)
- B 선택 시 배경: 핏빛 사당
- B 실패 시 거짓 귓속말은 다음 이벤트 시작 시점에 **무작위 형제 1명**에게 티어 환청과 같은 형식으로 발송

### 13.3 랜덤 이벤트 진행

- 풀 01~14에서 7개를 중복 없이 뽑아 슬롯 1~6, 8에 배치
- **슬롯 7은 보스(15) 고정**
- 각 랜덤 이벤트 종료 시 환경 잠식 전원 +5%
- 30% 이상 플레이어의 티어 환청은 각 랜덤 이벤트 시작 시 발동

### 13.4 이벤트 공통 규칙

- 보상(부적, 회복)은 별도 표기가 없으면 판정자에게
- 협동 판정의 보상 아이템은 최종 최고값 주사위의 주인에게
- "전원" 회복은 배신자를 제외하고 적용 (표시 없음)

## 14. Phase 3: 장승 앞의 결전

**배경 에셋:** 피눈물 장승
**상황:** 마을 경계의 거대한 천하대장군 장승 앞. 삼형제 중 누군가의 눈에서 피눈물이 흐른다. "내가... 누구지...?" 뒤편에서 광대탈을 쓴 마을 사람들이 턱밑까지 추격해 온다.

### 14.1 진입 판정 순서 (서버 상태머신 기준)

**0. 타겟 지정**
- 잠식도 **30% 이상** 형제(봇 포함) 중 가장 높은 1명
- 동점 우선순위: **인간 배신자 > 봇 > 기타 인간**. 같은 순위 안에서만 랜덤
- 타겟은 Display에 공개
- **타겟이 옥비녀를 보유하면:** 타겟을 제외한 형제 중 잠식도가 가장 낮은 1명에게 이동 (동점 랜덤, 봇·다른 배신자 포함)
  - Display 공개: "옥비녀가 요기를 거부하며 손에서 튕겨 나간다"

**1. 인간 전원 배신자** → 강제 잠식 엔딩 (1인 플레이는 해당 없음)

**2. 타겟 없음** (전원 30% 미만) → 무사귀환 엔딩. 옥비녀는 사용하지 않음

**3. 옥비녀 보유자 존재** → B-1 정화, **투표 없이 즉시 진행** (§14.3)

**4. 그 외** → A 루트 투표 (§14.4)

### 14.2 Phase 3 공통 규칙

- 흉/평/길 변이 없음
- 첫째 강제 성공 사용 불가
- 남아 있는 버프/디버프는 팀 측 판정에 적용
- 개입 창은 **팀 측이 졌을 때만** 열리고, **팀 측 주사위에만** 작동 (둘째 재굴림, 부적 +1)
- 배신자 측에는 개입 수단 없음
- 판정과 개입 창은 시계가 0이 된 뒤에도 끝까지 진행

### 14.3 B-1: 옥비녀로 정화를 시도한다

- 판정자: 옥비녀 보유자 (봇 가능)
- 직업 보정 없음
- 10분 절삭 없음. 진입 연출 후 즉시 판정

| 타겟 | 판정 | 성공 조건 |
|---|---|---|
| 인간 배신자 | 대립: 보유자 D6 vs 배신자 D6 | 보유자 최종값 **>** 배신자 값 (동점은 배신자 승) |
| 봇 또는 배신자가 아닌 인간 | 고정 기준 | 보유자 최종값 ≥ 4 |

- 성공 → **진엔딩: 정화**
- 실패 → **영원한 미로**

### 14.4 A 루트 (옥비녀 없음)

**시계:** 진입 시 남은 시간이 10분을 넘으면 **10분으로 절삭** [설정값]. 10분 미만이면 그대로. 연출은 "추격대가 턱밑까지 왔다"

**투표**
- 선택지: A-1 미끼 / A-2 돌파
- 타겟 본인을 포함한 인간 전원이 투표
- **투표 마감 = 시계 0**, 전원이 투표를 마치면 즉시 마감
- 시계 0 시점에 **유효표가 0표면 강제 잠식 엔딩**. 1표 이상이면 다수결, 동률은 랜덤

| 선택지 | 판정 | 성공 | 실패 |
|---|---|---|---|
| A-1. 잠식된 형제를 미끼로 두고 도망친다 | 없음 | 비극적 탈출 | - |
| A-2. 마지막 힘으로 형제를 물리치고 탈출한다 | 협동: 타겟 제외 전원 굴림, 최고값 | 탈출: 결별 | 전멸 |

**A-2 성공 조건**

| 타겟 | 성공 조건 |
|---|---|
| 인간 배신자 | 최고값 **>** 배신자 D6 (동점은 배신자 승) |
| 봇 또는 배신자가 아닌 인간 | 최고값 ≥ 5 |

### 14.5 1인 플레이에서 본인이 타겟인 경우

1인 플레이에는 배신자 모드가 없으므로 본인은 **배신자가 아닌 인간 타겟**으로 처리합니다.

**옥비녀가 있는 경우 (B-1)**
- 옥비녀는 타겟(본인)을 제외하고 잠식도가 낮은 봇에게 이동 (동점 랜덤)
- 봇이 굴리며, 고정 기준 **최종값 4 이상**
- 판정 실패 시 본인은 팀 측으로서 개입 창 사용 가능 (부적 +1, 둘째라면 재굴림)

**옥비녀가 없는 경우 (A 루트)**
- **A-1 비활성.** 자신을 미끼로 두고 도망친다는 선택지가 성립하지 않으므로 표시하지 않음
- **A-2 한 개 선택지로 투표 유지.** 시계 0까지 누르지 않으면 유효표 0으로 강제 잠식 엔딩
- A-2 선택지 텍스트 변경:
  > 마지막 이성을 쥐어짜내며, 형제들이 나를 제압하도록 둔다
- 굴림은 봇 2명이 자동으로 진행 (§11). 최고값 5 이상이면 성공
- 판정 실패 시 본인은 개입 창 사용 가능 (부적 +1). 둘째 재굴림은 본인 주사위가 없으므로 사용 불가

**엔딩 내레이션 분기** (룰과 승패는 동일)

| 결과 | 내레이션 |
|---|---|
| A-2 성공 | 형제들에게 제압당한 채 끌려 나와 함께 경계를 넘는다 (전원 탈출) |
| A-2 실패 | 전멸 (기존과 동일) |

## 15. 엔딩

엔딩 연출은 게임 시계 밖(최대 20분)에서 진행합니다.

| 엔딩 | 조건 | 배신자 | 연출 에셋 |
|---|---|---|---|
| 진엔딩: 정화 | 옥비녀 + B-1 성공 | 패배 (정화되어 함께 귀환) | 옥비녀, 피눈물 장승 |
| 굿엔딩: 무사귀환 | Phase 3 진입 시 타겟 없음 | 존재 불가 | 피눈물 장승 |
| 탈출: 결별 | A-2 성공 | 패배 | 피눈물 장승 |
| 비극적 탈출 | A-1 채택 | 패배 | 요괴화 탈 (버린 형제가 배신자일 때) |
| 전멸 | A-2 실패 | **승리** | 요괴화 탈 |
| 영원한 미로 | B-1 실패 | **승리** | 요괴화 탈 |
| 강제 잠식 | 타임오버, Phase 3 유효표 0, 인간 전원 배신자 | **승리** | 요괴화 탈, 노이즈 |

- **배신자가 한 명도 없는 판에서는 배신자 승패를 판정하지 않는다.** 위 표의 배신자 열은 배신자라는 주체가 있어야 성립한다(§10.3). 배신자 없이 전멸·영원한 미로·강제 잠식으로 끝나면 배신자 승패는 **해당 없음**이다
- 1인 플레이에서 본인이 타겟인 A-2 성공은 "탈출: 결별" 대신 전용 내레이션 사용 (§14.5)
- **엔딩 화면에서 배신자의 승패와 정체를 공개한다.** 판이 끝난 뒤이므로 심리전에 영향이 없고, 합방·스트리밍에서 관전이 완성되는 지점이다. 배신자가 0명이면 "배신자 없음"으로 표시한다 (§17, §21)

- **좌석별 연결 상태는 Display에만 표시**하고 표기는 "연결 끊김"으로 통일한다. "봇 대행"이라는 표현은 쓰지 않는다. 잠식도·인벤토리와 무관해 심리전 정보가 아니며, 관전자가 특정 좌석이 조용한 이유를 알 수 있다. 본인 폰(Controller)에는 다른 좌석의 연결 상태를 표시하지 않는다
- 배신자 UI는 일반 플레이어와 완전히 동일
- 붉은 메시지는 진짜와 가짜 모두 3초 후 소멸, 동일 연출
- **좌석 표시 이름과 현재 진행 번호는 공개한다.** 다만 **총 이벤트 개수와 남은 개수는 공개하지 않는다.** 남은 개수를 알면 부적을 언제 쓸지가 계산 문제가 되어, 압박 지표는 게임 시계 하나로 남긴다
- **배신자 여부는 엔딩 전까지 서버만 안다.** 엔딩 화면에서 승패와 정체를 함께 공개한다 (§15)

## 20. 알려진 한계

- **2인 플레이 투표 역산:** 득표 수만으로 상대의 선택을 역산할 수 있음. 3인도 만장일치가 아니면 부분 추론 가능. 마감 후 공개로 실시간 역산만 차단
- **진입 환청 디버프 수:** 익명 디버프의 크기로 부적 미보유자 수를 일부 추정할 수 있음. 하한 -2로 부분 차단
- **오프라인 합방 화면 노출:** 옆 사람 폰이나 캠에 화면이 비치는 것은 규칙으로 막을 수 없음. 붉은 메시지 3초 소멸과 가짜 메시지로 완화
- **인간 0명 구성의 Phase 3 A 루트:** 봇은 투표하지 않으므로(§11) 인간이 없는 구성은 A 루트 투표에서 언제나 유효표 0이 되어 강제 잠식으로 끝남(§14.4). 실제 플레이에는 인간이 1명 이상 있으므로 규칙을 바꾸지 않음. 봇 자동 대전의 `--humans 0`은 **시계 소모 상한 참고치로만** 읽고, 엔딩 분포는 `--humans 1~3`으로 읽음

| 개입 단계의 종료 시점 **(확정)** | 그 단계의 수단이 소모되면 남은 시간을 기다리지 않고 다음 단계로 간다. 부적은 판정당 1개라 다른 보유자도 쓸 수 없고 사용 사실도 공개 정보라 새는 정보가 없음 | §7.2 |
| 시간 페널티가 없는 선택지의 흉·길 **(확정)** | 이미 있는 시간 페널티만 가감하고, 없으면 새로 만들지 않음 | §6.2 |
| 길 변이의 증가 가능한 보상이 여러 개일 때 **(확정)** | 전부 한 단계씩 올림 | §6.2 |
| 봇 100% 방해의 후보 선정 **(확정)** | 발동 가능한 수단 중에서 고른다. 부적 보유자가 없으면 팀 디버프만 후보. "게임당 1회"는 효과가 실제로 일어나는 1회 | §11 |
| 100%(배신자) 좌석의 티어 효과 **(확정)** | 티어 환청·가짜 라벨·가짜 붉은 메시지 대상에서 제외. 배신자는 이미 실제 변이를 전부 봄 | §4.3, §16 |
| 인간 0명 구성의 Phase 3 A 루트 **(확정)** | 항상 유효표 0 → 강제 잠식. 룰 그대로 두고 알려진 한계로 기록. `--humans 0`은 시계 소모 상한 참고치 | §20 |
| 배신자 없는 판의 배신자 승패 **(확정)** | 배신자가 0명이면 승패를 판정하지 않고 **해당 없음**으로 둔다. 봇 자동 대전의 배신자 승률도 배신자가 1명 이상인 판만 모집단으로 센다 | §15 |
| 좌석 연결 상태의 공개 범위 **(확정, 2026-09-19)** | Display에만 좌석별로 "연결 끊김"을 표시한다. "봇 대행" 표현은 쓰지 않고, Controller에는 다른 좌석의 연결 상태를 표시하지 않는다 | §17 |
| Display의 방 운영 조작 **(확정, 2026-09-19)** | Display에는 게임 조작이 없다. 게임 시작·봇 지정·일시정지·재개는 룰이 아니라 방 운영이라 예외로 호스트 Display가 보낸다 | §1 |
| 결과 표시 체류 시간 **(확정, 2026-09-19)** | 결과 적용 단계에 **3초**를 머문다. 서버 단계로 두어 Display와 모든 Controller가 같은 시점에 같은 결과를 본다. 연출 신호(cue)만으로 처리하면 Controller가 결과를 보지 못하고 신호가 유실되면 아예 표시되지 않는다 | §19 |
| 엔딩의 배신자 공개 **(확정, 2026-09-19)** | 엔딩 화면에서 배신자의 승패와 정체를 공개한다. 배신자가 0명이면 "배신자 없음"으로 표시한다 | §15, §17 |
| 게임 중 좌석 이름과 진행 번호 **(확정, 2026-09-19)** | 좌석의 표시 이름과 현재 진행 번호는 공개한다. 총 이벤트 개수와 남은 개수는 공개하지 않는다 | §17 |

### 21.1 설정값 조정 이력

봇 자동 대전·플레이 검증 결과로 §19 설정값을 바꾼 기록입니다. **한 번에 한 값만** 바꿔 다음 측정에서 원인을 귀속할 수 있게 합니다.

|---|---|---|---|---|
