## 착수 전 확정 (2026-09-19)

계획 9절의 해석 항목 13건이 모두 확정됐다. 결정 내용은 `docs/m4-plan.md` 9절 표에 있고,
그중 **10건은 계획안대로**, **3번·4번은 수정**, **12번은 보강**이다. 문서에 반영한 곳은 다음과 같다.

| 대상 | 반영 내용 |
|---|---|
| `rulebook-v3.md` §1 | Display에는 **게임 조작이 없다**. 시작·봇 지정·일시정지·재개 같은 **방 운영은 예외**라고 명시 |
| `rulebook-v3.md` §15 | 엔딩 화면에서 배신자의 **승패와 정체를 공개**한다. 배신자 0명이면 "배신자 없음" |
| `rulebook-v3.md` §17 | 공개 표에 좌석 표시 이름·현재 진행 번호·엔딩의 배신자 공개를 추가. **총 이벤트 개수는 비공개**, 배신자 여부는 "엔딩 전까지" 서버만 |
| `rulebook-v3.md` §19 | 시간 표에 **결과 표시 3초** 추가 |
| `rulebook-v3.md` §21 | (확정) 행 4건 — Display의 방 운영 조작, 결과 표시 체류 시간, 엔딩의 배신자 공개, 게임 중 좌석 이름과 진행 번호 |
| `architecture.md` §5.3 | `RESOLUTION`의 즉시 전이 서술을 **3초 체류**로 수정. 엔딩으로 가는 경우는 체류하지 않는다고 명시 |
| `architecture.md` §7.1 | 호스트 Display가 보내는 명령은 **방 운영뿐**이라고 명시 |
| `architecture.md` §7.2 | 스냅샷에 `serverNow`를 실어 클라이언트가 시계 오차를 보정한다 |
| `architecture.md` §7.3 | 투영 표에 좌석 표시 이름·진행 번호·엔딩의 배신자 공개 행 추가. 총 이벤트 개수는 어떤 투영에도 넣지 않는다 |
| `architecture.md` §8 | 운영 규칙에 **개발용 시계 단축** 행 추가 (개발 환경에서만, 운영에서는 무시) |
| `architecture.md` §9.1 | 스토어 목록을 `auth.ts, play.ts`로 수정. 로비·게임이 같은 방 세션을 쓰는 이유를 명시 |
| `m4-plan.md` 9절 | 표를 **확정된 결정** 표로 바꾸고, 3번 결정이 바꾸는 것을 9.1에 정리 |
| `m4-plan.md` 전제·1·2.5·4.4·5·10절 | 확정 내용을 본문에 반영. M4-1 파일 목록에 승인된 서버·shared 변경을 추가 |
